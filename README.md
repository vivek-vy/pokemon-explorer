 modern React-based web app to explore Pokémon details, compare stats between two Pokémon, manage favorites (with localStorage), and experience a sleek, responsive UI.

## 🌟 Features

- 🔍 **Search & View Details** of individual Pokémon
- 📊 **Compare Two Pokémon** side-by-side with stats and images
- ⭐ **Add to Favorites** (saved in localStorage)
- ⏪ **Go Back** button for smooth navigation
- 🎨 Styled with custom CSS for clarity and responsiveness
- 🌐 Powered by [PokéAPI](https://pokeapi.co)
